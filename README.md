# Career Navideer development build

Static production-quality concept build for careernavideer.net.

## Pages
- Home
- How It Works
- Evidence / Career Decision Intelligence
- Solutions
- About
- Request a Demo

## Development safeguards
- `robots.txt` blocks indexing until approval.
- Demo form does not transmit data.
- Evidence page explicitly avoids presenting CDI as a validated score, diagnosis, predictor, or causal-effectiveness claim.
